# Launch checklist (M8)

Everything here is prepared but **not executed** — each item publishes something under a name, to
an audience, and needs a human to press it.

## Before anything is published

- [ ] **Re-check the name.** `mispick` was free on PyPI, npm and GitHub on 2026-09-23. Names can be
      taken at any time; check again at the moment of reserving it.
      ```bash
      curl -s -o /dev/null -w '%{http_code}\n' https://pypi.org/pypi/mispick/json   # want 404
      curl -s -o /dev/null -w '%{http_code}\n' https://registry.npmjs.org/mispick    # want 404
      ```
- [ ] **Decide the GitHub owner.** `pyproject.toml` and the README currently point at
      `github.com/msc35/mispick`. Change both if that is wrong.
- [ ] **Reserve the npm name** even though this is a Python package, so `npx mispick` cannot become
      someone else's tool.

## PyPI

The wheel and sdist build cleanly and the wheel has been verified end to end:

```bash
uv build
uvx --from dist/mispick-0.1.0-py3-none-any.whl mispick run --snapshot tools.json --model mock
```

- [ ] `uv publish` to TestPyPI first, install from it, run it once.
- [ ] `uv publish` to PyPI.
- [ ] Tag `v0.1.0` and cut a GitHub release.

## The Action

- [ ] The README and examples reference `mispick/mispick@v0.1.0`. That tag has to exist on the
      chosen owner before any of it works.
- [ ] Publish to the GitHub Marketplace (optional; the `uses:` path works without it).

## Benchmark and Pages

- [ ] Run `benchmark/pick.py` and `benchmark/capture.py`. **This launches other people's MCP
      servers locally through npx/uvx**, which is why `benchmark/snapshots/` ships empty.
- [ ] Read the captured snapshots before measuring anything.
- [ ] Run the `benchmark` workflow, review the artifact, then run `pages` against that run id.
      Pages deploys are deliberately manual — the site names other people's projects.
- [ ] Enable Pages on the repository.

## Announcements

Each of these puts the project in front of other people. Worth reading the wording once more first,
especially anything comparing mispick to `whichtool` or `toolfit` — both are 0-star projects by
individuals, and the comparison in the README should stay factual and generous.

- [ ] Submit to the official MCP registry.
- [ ] PR to `punkpeye/awesome-mcp-servers` and similar lists.
- [ ] Anywhere else you plan to post.
